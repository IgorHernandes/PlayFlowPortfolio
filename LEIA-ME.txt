# Portfólio PlayFlow

## Como acessar o projeto

### Opção 1 — Clonar o repositório com Git

1. Instale o [Git](https://git-scm.com/downloads), caso ainda não tenha.
2. Abra o terminal ou o Visual Studio Code.
3. Execute o comando:

```bash
git clone https://github.com/IgorHernandes/PlayFlowPortfolio.git
```

4. Entre na pasta do projeto:

```bash
cd PlayFlowPortfolio
```

5. Abra a pasta no Visual Studio Code:

```bash
code .
```

6. Abra o arquivo `index.html` ou utilize a extensão Live Server para visualizar o portfólio no navegador.

### Opção 2 — Download ZIP

1. Acesse o repositório no GitHub.
2. Clique em **Code → Download ZIP**.
3. Extraia o arquivo ZIP.
4. Abra a pasta extraída no Visual Studio Code.
5. Abra o arquivo `index.html` no navegador.

## Requisitos

- Git (somente para a opção de clonagem).
- Navegador atualizado.
- Visual Studio Code (opcional).

Não é necessário instalar dependências ou configurar um servidor para visualizar o portfólio localmente.
